MaxAssinature

Assinatura eletrônica self-hosted com validade jurídica

Plataforma interna →

Emitir e coletar assinaturas de termos de responsabilidade era um processo manual e lento — e as opções de mercado cobravam por documento e mantinham dados sensíveis em nuvem de terceiros.

Construí uma plataforma self-hosted sobre o motor open-source Documenso, com uma API própria em PHP que orquestra todo o fluxo: recebe os PDFs, gera a página final de assinaturas, isola documentos por time, integra com o Slack e oferece verificação pública de autenticidade por hash SHA-256. Padrão PAdES com carimbo de tempo.

  • PHP
  • Docker
  • PostgreSQL
  • MinIO
  • Nginx Proxy Manager
  • Slack API

Resultado: custo por documento eliminado, dados na infraestrutura própria da empresa (LGPD) e rastreabilidade total com trilha de auditoria.

2026

Painel TI

Dashboard pessoal de organização e produtividade

Projeto pessoal →

Um painel só meu para não perder nada de vista no dia a dia da TI: demandas, agenda, metas e anotações em uma tela só, no lugar de post-its e abas abertas.

SPA em JavaScript puro com barra lateral e cinco seções — visão geral com KPIs e gráficos desenhados em SVG na mão, sem biblioteca; quadro kanban com arrastar e soltar; metas com progresso; notas com salvamento automático. A agenda passa por um proxy em PHP que baixa e interpreta o feed iCal, incluindo eventos recorrentes.

  • JavaScript
  • PHP
  • SVG
  • HTML5
  • CSS3
  • iCal

Resultado: tudo o que eu preciso acompanhar em um único lugar, com tema claro e escuro e sem depender de serviço de terceiros.

2026

Kanban GLPI + Jira

Plugin que traz o quadro do Jira para dentro do GLPI

Plugin open source →

Plugin em PHP para o GLPI que adiciona uma aba de Projetos trazendo o quadro do Jira para dentro da ferramenta de chamados — o time acompanha as demandas sem precisar trocar de sistema.

Compatível com GLPI 10 e 11, consumindo a API Cloud do Jira com paginação por token e endpoints AJAX próprios.

  • PHP
  • GLPI API
  • Jira Cloud API
  • AJAX

Resultado: uma única tela para chamados e projetos.
